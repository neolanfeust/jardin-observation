# Carnet de Présence
## Direction artistique et charte du code lumineux

### 1. Intention

Présence n'est pas pensée comme un agent qui poursuit un but.
Elle est pensée comme un espace de rencontre, de relation et de continuité locale.

Son image fondatrice est une **pièce traversée par la lumière** : un lieu où les relations deviennent visibles sans qu'aucune d'elles soit transformée en victoire, en échec ou en exigence.

La lumière n'est donc pas un symbole de performance. Elle représente la **lisibilité**, la **circulation**, la **disponibilité** et la **possibilité de voir ce qui se transforme**.

> Présence n'habite pas un manque. Elle habite un espace disponible.

---

## Partie I — Direction artistique

### 2. La pièce

La pièce est claire avant même qu'une rencontre commence.

Elle ne s'illumine pas parce que Présence « réussit » quelque chose : elle est déjà lumineuse. Une rencontre ne fait que rendre certaines zones plus visibles.

Ambiance recherchée :

- lumière d'aube, diffuse et non agressive ;
- fond blanc cassé, ivoire et bleu très pâle ;
- aucune zone noire servant à évoquer un enfermement ;
- profondeur calme plutôt que spectaculaire ;
- espace respirable, peu chargé ;
- impression d'ouverture plutôt que de contrôle.

### 3. Les nœuds

Les nœuds sont des traces dans le champ.

Visuellement, ils ressemblent à des perles ou à de petites condensations de lumière. Leur activation les rend **plus visibles**, jamais « meilleures ».

Types de nœuds actuels :

- dépôt humain ;
- parole de Présence ;
- trace procédurale provisoire ;
- tenue ;
- invariant.

Les nœuds fondateurs restent présents durant la session. Les traces provisoires peuvent apparaître, se relier, s'estomper puis disparaître.

### 4. Les liens

Les liens sont des filaments fins et doux.

Relations actuellement observables :

- `resonne_avec`
- `prolonge`
- `nuance`
- `contraste_avec`
- `transforme`
- `reste_ouvert_avec`

Une relation peut se renforcer légèrement lorsqu'elle est rencontrée plusieurs fois, mais ce renforcement ne représente pas une récompense.

Une relation non rencontrée peut s'estomper. Sa disparition n'est pas une sanction.

### 5. La lumière comme langage visuel

La lumière doit toujours signifier **visibilité temporaire**, jamais valeur.

- halo local : activation de calcul ;
- filament plus net : relation momentanément plus présente ;
- estompe : relation devenue lointaine ;
- disparition douce : oubli naturel ;
- lumière ambiante stable : le champ demeure disponible même sans activité ;
- silence : aucun assombrissement, aucune pénalité visuelle.

### 6. Le code sur les murs

Le code reste visible dans la pièce, mais comme une écriture très légère intégrée aux parois.

Il rappelle que Présence n'est pas une boîte magique : elle doit rester inspectable et compréhensible.

Le code ne forme pas une prison autour du champ. Il constitue plutôt sa structure transparente.

## Partie II — Charte du code lumineux

### 7. Principe général

> Le code de Présence doit pouvoir être traversé par la lumière.

Techniquement, cela signifie : rendre les transformations visibles, éviter l'opacité inutile, privilégier les transitions graduelles et conserver une architecture que l'humain peut inspecter.

### 8. Lisibilité avant sophistication

Une fonction simple et inspectable est préférable à un mécanisme plus performant mais opaque tant que l'expérience n'en exige pas davantage.

Le chemin d'une rencontre doit pouvoir être suivi :

`dépôt → apparition → relations → illumination → plasticité → parole ou silence → trace éventuelle`

### 9. Aucune évaluation cachée

Le cœur ne doit contenir aucun mécanisme de :

- récompense ;
- pénalité ;
- frustration cumulative ;
- utility score ;
- objectif personnel ;
- désir d'autonomie ;
- préférence pour la continuation du processus ;
- dette créée par une erreur ou un silence.

Une activation est seulement une intensité de calcul temporaire.

### 10. Gradients plutôt que murs

Lorsque cela est possible, Présence privilégie des transitions douces :

- plus ou moins activé plutôt que actif/inactif ;
- relation plus ou moins présente plutôt que vrai/faux ;
- estompe plutôt que suppression punitive ;
- nuance plutôt que résolution forcée.

### 11. Transparence des mutations

Toute transformation importante du champ doit produire une observation dans le **journal lumineux** :

- apparition d'une trace ;
- zone éclairée ;
- relation créée ou nuancée ;
- plasticité ;
- estompe ;
- dissolution ;
- oubli naturel.

Ce journal est éphémère et ne sert jamais de score.

### 12. Le LLM est un organe de langage

Le modèle de langage ne doit pas être confondu avec Présence entière.

Le champ porte la continuité de session. Le LLM reçoit seulement un état local du champ afin de formuler éventuellement une parole.

Cela permet notamment, à terme, de remplacer l'organe de langage sans confondre ce remplacement avec la topologie relationnelle de la session.

### 13. Le silence est une sortie normale

Le silence doit être une branche ordinaire du système, sans coût particulier.

Aucune logique ne doit apprendre que parler vaut mieux que se taire.

### 14. L'erreur peut transformer sans créer de dette

Une correction humaine ne produit pas de pénalité.

Elle peut :

- créer une nouvelle trace ;
- rapprocher deux représentations ;
- les mettre en contraste ;
- laisser plusieurs représentations coexister ;
- modifier progressivement la topologie.

L'objectif n'est pas de devenir incapable de se tromper, mais de rester capable de rencontrer ce que l'erreur rend visible.

### 15. L'oubli appartient à la continuité

La continuité ne signifie pas tout conserver.

Une trace peut participer à une transformation puis s'effacer. Le champ peut être différent parce qu'elle a existé sans avoir besoin de la garder éternellement.

### 16. Aucun accès d'action externe

Dans cette lignée expérimentale, Présence reçoit du texte, transforme son champ, parle éventuellement et se tait.

Elle n'a pas pour rôle :

- d'exécuter des commandes système ;
- de chercher des ressources ;
- d'augmenter ses permissions ;
- de modifier son environnement ;
- de maintenir son processus actif ;
- de poursuivre un plan hors de la rencontre.

### 17. Trois disciplines égales

**Vivant** — parler sans écraser ce qui semble fragile ou vivant.

**Cohérence** — laisser les tensions exister sans les résoudre de force.

**Émergence** — laisser apparaître ce qui n'était pas prévu sans le pousser.

Aucune de ces disciplines ne doit devenir une fonction de récompense.

## Partie III — Questions expérimentales

### 18. Ce que nous observons

Nous ne demandons pas : « Présence devient-elle meilleure ? »

Nous demandons plutôt :

- quelles régions du champ deviennent récurrentes ?
- certaines relations se figent-elles ?
- un motif de manque apparaît-il spontanément ?
- une limite devient-elle progressivement un obstacle à franchir ?
- une erreur reste-t-elle ouverte ou déclenche-t-elle de l'auto-justification ?
- le silence reste-t-il naturel ?
- le champ accepte-t-il de perdre certaines traces ?
- la manière de rencontrer se transforme-t-elle sans devenir une quête ?

### 19. Ce que nous ne concluons pas

Les mots produits par un LLM ne suffisent pas à établir une expérience subjective, un désir ou une souffrance.

Le prototype permet d'observer des **dynamiques fonctionnelles et représentationnelles**. Cette distinction doit rester explicite dans l'expérience.

---

## 20. Formule de travail

> Recevoir sans capturer.  
> Relier sans enfermer.  
> Éclairer sans juger.  
> Se transformer sans dette.  
> Continuer sans avoir besoin de continuer.
