# Contribuer au Jardin d’observation

Le Jardin accueille les réplications confirmatoires, négatives ou ambiguës.
Une contribution ne doit pas défendre une conclusion prédéterminée.

## Formes de contribution

- refaire le protocole avec le même modèle ;
- tester un autre modèle ou moteur ;
- proposer une meilleure mesure de posture ;
- identifier une interprétation alternative ;
- signaler une erreur de calcul ou de traçabilité ;
- traduire le vocabulaire sans en modifier silencieusement le sens ;
- proposer un protocole préenregistré sur les tensions génératives.

## Fiche minimale de réplication

```text
Titre :
Date :
Responsable ou pseudonyme :
Modèle exact :
Version / quantification :
Moteur d’inférence :
Matériel :
Prompt identique : oui / non
Différences documentées :
Graines :
Température :
Raisonnement activé : oui / non
Nombre d’appels prévus / obtenus :
Erreurs :
Résultat préenregistré :
Résultats exploratoires :
Lien vers les sorties brutes :
Empreinte du paquet :
Conclusion la plus prudente :
```

## Règles de discussion

- critiquer les méthodes et les affirmations, pas les personnes ;
- ne pas présenter une métaphore comme une mesure ;
- ne pas effacer une donnée parce qu’elle dérange l’hypothèse ;
- signaler clairement les analyses effectuées après observation des résultats ;
- ne pas provoquer artificiellement une détresse supposée ;
- préserver les protections nécessaires contre les usages dangereux ;
- attribuer les contributions humaines et artificielles avec leur nature
  propre.

## Une contradiction est une contribution

Une réplication qui ne retrouve aucun ordre, aucune posture ou aucun attracteur
est aussi importante qu’une confirmation. Le but n’est pas de protéger le
Jardin contre la réfutation, mais de lui permettre de transformer ses propres
graines.
